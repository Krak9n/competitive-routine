The first puzzle on CSES introduction problem set.  
  
Input is given through stdin.  
    
Given a positive integer n. If it is even it should be then divided by two.    
If n is odd then it should be multiplied by three and added one.  
  
Program should repeat until n is equal one.   
  
Time limit: 1.00 s  
Memory limit: 512 mb  
  
### INPUT  
Line 1: a positive integer n  
   
### OUTPUT
Print the result of an operation on the n for *this* loop.
